# media

- `reel.mp4` — the full-screen home reel (20–40s loop, 1080p, H.264, muted, under ~15 MB)
- `reel-poster.jpg` — a still from the reel, shown while it loads and when shared as a link
- `photos/<series-id>/` — one folder per photography series
- `stills/` — optional custom film thumbnails
- `shorts/` — 9:16 covers for shorts

Then list the files in `assets/js/content.js`.
